# 🌎 Planeta Água — SNCT 2025

> **Tema:** *"Cultura Oceânica para Enfrentar as Mudanças Climáticas no Meu Território"*

Este projeto foi desenvolvido para a **Semana Nacional de Ciência e Tecnologia 2025 (SNCT)**.  
O objetivo é promover a conscientização sobre o papel dos oceanos no equilíbrio climático e incentivar o uso da **tecnologia como ferramenta de preservação ambiental**.

---

## 💡 Sobre o Projeto

O site apresenta:
- 🌊 **Informações educativas** sobre o papel dos oceanos  
- ☀️ **Impactos das mudanças climáticas** no meio ambiente  
- ♻️ **Ações locais sustentáveis** que cada cidadão pode fazer  
- 💧 **Simulador interativo "AquaTech"**, um painel que representa sensores de **pH, turbidez e temperatura** da água, em tempo real
- ### 💧 Sobre o AquaTech

O **AquaTech** é um projeto de **monitoramento inteligente da qualidade da água**, desenvolvido com foco em acessibilidade e sustentabilidade.  
Ele une conceitos de **tecnologia, ciência de dados e consciência ambiental** para demonstrar como a inovação pode contribuir para enfrentar as mudanças climáticas no território local.

#### 🔬 Sensores Utilizados (simulados no site)
- **Sensor de pH:** mede a acidez ou alcalinidade da água, indicador essencial para a vida aquática.  
- **Sensor de Turbidez:** avalia a presença de partículas e sedimentos, apontando possíveis poluições.  
- **Sensor de Temperatura:** monitora variações térmicas que afetam ecossistemas marinhos e fluviais.  

#### ⚙️ Estrutura proposta do protótipo físico
- **Microcontrolador:** Arduino UNO ou ESP32.  
- **Comunicação:** transmissão de dados via Wi-Fi ou Bluetooth.  
- **Interface Web:** painel visual (este site), exibindo leituras em tempo real.  
- **Banco de dados (futuro):** armazenamento e análise histórica dos dados coletados.  

#### 🌍 Aplicações reais
- Monitoramento de rios, represas e praias locais.  
- Apoio a escolas e comunidades em projetos ambientais.  
- Envio de dados para plataformas de pesquisa ou órgãos ambientais.

#### 🚀 Expansão futura
- Integração com dashboards IoT (como ThingSpeak ou Node-RED).  
- Sistema de alertas automáticos (quando parâmetros fogem do ideal).  
- App mobile para leitura remota dos sensores.

> 💡 O AquaTech simboliza a união entre **tecnologia, ciência e sustentabilidade**, incentivando o protagonismo jovem na preservação do planeta.
