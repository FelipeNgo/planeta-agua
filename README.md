# 🌎 Planeta Água — SNCT 2025

> **Tema:** *"Cultura Oceânica para Enfrentar as Mudanças Climáticas no Meu Território"*

Este projeto foi desenvolvido para a **Semana Nacional de Ciência e Tecnologia 2025 (SNCT)**.  
O objetivo é promover a conscientização sobre o papel dos oceanos no equilíbrio climático e incentivar o uso da **tecnologia como ferramenta de preservação ambiental**.

---

## 💡 Sobre o Projeto

O site apresenta:
- 🌊 **Informações educativas** sobre o papel dos oceanos  
- ☀️ **Impactos das mudanças climáticas** no meio ambiente  
- ♻️ **Ações locais sustentáveis** que cada cidadão pode fazer  
- 💧 **Simulador interativo "AquaTech"**, um painel que representa sensores de **pH, turbidez e temperatura** da água, em tempo real
